# corpus/

Test documents for the extractor. **No PDF is committed** — with a single
exception: the two SciELO articles in `vendored/` (byte-for-byte copies,
CC BY 4.0, ADR-103). Full policy: [`docs/extractor/CORPUS.md`](../docs/extractor/CORPUS.md).

```
corpus/
  manifest.yaml     public documents (id, level, language, license, sha256…)   [git]
  golden/           expected output for the synthetic documents                [git]
  sentences/        annotated sentence corpus, public-domain pt/en text         [git]
  vendored/         the 2 SciELO PDFs, the only committed PDFs                  [git]
  public/           downloaded by `pnpm corpus:fetch`                           [ignored]
    synthetic/      generated from the specifications                          [ignored]
```

- **Public** — open-access or public-domain PDFs downloaded into `corpus/public/` and verified against the SHA-256 in `manifest.yaml`.
- **Synthetic** — 12 `syn-*` documents generated by `pnpm corpus:synthetic` from their own specification (`packages/eval/src/specs.ts`): the specification *is* the truth, so they carry the goldens.
- **Vendored** — the two SciELO articles, committed byte for byte because SciELO returns `403` to GitHub Actions IPs (ADR-034/ADR-103). `pnpm corpus:fetch` copies them locally with no network, checking the manifest SHA-256 first.
- **Private** — copyrighted books that live **outside** the repository, in the folder named by the environment variable `CORPUS_PRIVATE_DIR` (or the `.env` file in the repo root). Never committed, never quoted in commits, issues or PRs. The runner merges both manifests automatically.

## `pnpm corpus:fetch`

Downloads whatever is missing into `corpus/public/` and validates every file:

- file already present with the right hash → **no request** (this is what the CI cache relies on);
- `vendored:` entry → copied from `corpus/vendored/` with no network, SHA-256 checked (`exit 1` on mismatch);
- `generated: true` → the synthetic PDF is built locally if missing; a hash mismatch tells you to run `pnpm corpus:synthetic` (it never overwrites on its own);
- network errors / `5xx` / `429` / `403` → 3 retries (1 s, 2 s), then the next `fallback_urls` entry, then `exit 1`;
- a PDF on disk with no manifest entry → warning only;
- no `CORPUS_PRIVATE_DIR` → one warning and `exit 0`: the public corpus is enough.

## License rule

Only **CC BY, CC BY-SA or verified public domain** documents may enter the
public manifest (the full verdict table, including what is refused — `CC BY-ND`,
login-walled downloads, licenses that cannot be confirmed — is in
[`docs/extractor/CORPUS.md`](../docs/extractor/CORPUS.md)). Never claim a
license from memory: every entry records the official page URL, the exact
license line and the verification date (`license`, `license_url`,
`verified_on`). Private (copyrighted) documents are for local testing only and
are governed by the same rule in [`CONTRIBUTING.md`](../CONTRIBUTING.md): no
PDF or copyrighted text ever enters a commit, issue or pull request.

## Adding a document

Follow the skill [`.opencode/skills/add-corpus-pdf/SKILL.md`](../.opencode/skills/add-corpus-pdf/SKILL.md):
verify the license on the official page, pick the level (N1–N5) and language,
add the entry to `corpus/manifest.yaml` with the SHA-256, run
`pnpm corpus:fetch` and `pnpm eval`. If the source blocks GitHub (403), the
alternative is to vendor the file like the SciELO pair — or pick another source.
